# JDMart - Marketplace Platform

JDMart is a modern multi-role e-commerce and services platform connecting Buyers, Sellers, Riders, Job Seekers, Employers, and Admins.

Ported from Flutter to a React + TypeScript + Vite application.

## Features

- **Multi-Role Platform**: Switch perspectives seamlessly across Buyer, Seller, Rider, Job Seeker, Employer, and Admin with dynamic metrics.
- **Flash Deals & Top Offers**: Live countdown timers, discount percentages, and interactive product details.
- **Product Showcase**: Detailed specifications, reviews count, customer ratings, and free delivery thresholds.
- **Shopping Cart & Checkout**: Live cart badge, item addition, quantity modification, price calculations in Le, and order simulation.
- **Navigation & Drawer**: Custom drawer with JDMart brand identity, active icons, categories, deals, order tracking, and settings.
- **Authentication Flows**: Complete onboarding flow, login with password visibility toggle, registration, and password recovery.
- **Responsive Mobile-First Interface**: Bottom app bar with floating action button (FAB) for quick actions.

## Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Typography**: Poppins (Google Fonts)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
